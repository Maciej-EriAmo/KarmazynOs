# TB.4 — self-host kcc (w K0)

**Cel:** `kcc` napisany w K0 kompiluje siebie.

**Status:** **Phase 4** — dump C na dysk + gcc + run (`verify_selfhost`). Host `kcc` = stage0.

## Fazy

| Faza | Deliverable | Gate |
|------|-------------|------|
| **0** | `lex_common` / `tok_kind` | ✅ |
| **1** | `lex_engine` / `lex_buffer` | ✅ |
| **2** | `parse_mini` | ✅ |
| **3** | `emit_mini` — IR, sem, emit C, eval | ✅ |
| **4** | Self-host loop (kcc_k0 dump C → gcc → run) | ✅ `KCC_SELFHOST_OK` |

## Pipeline Phase 3

```text
ASCII src → lex_fill → IR (RPN stmts) → sem_check → eval_program
                                              ↘ emit_program → C as [i32] bytes
```

### IR ops
| Op | Meaning |
|----|---------|
| 1 | INT value |
| 2 | IDENT span |
| 3/4 | ADD / SUB |
| 5 | LET name + expr…END |
| 6 | RET expr…END |
| 7 | FN |
| 8 | END |

### Emit shape
```c
int main(void){
  int32_t x = …;
  return …;
}
```
Guest C from `emit_program` starts with `#include <stdint.h>` and `/* generated by kcc-k0 */`.
`putchar` is a host-kcc libc builtin (P4 dump).

## Pliki

```text
lex_common.k0  lex_engine.k0
tok_kind.k0    lex_buffer.k0
parse_mini.k0  emit_engine.k0   (no main)
emit_mini.k0   (P3 fixtures)
selfhost_dump.k0  (P4 dump)
```

```powershell
..\kcc\target\release\kcc.exe emit_mini.k0 --cc -o ..\..\out\kcc\emit_mini
.\toolchain\verify_selfhost.ps1
# → KCC_SELFHOST_OK
.\toolchain\verify_kcc.ps1
# includes Phase 4
```

## Phase 3 fixtures (emit_mini)

| Id | Case | Expect |
|----|------|--------|
| A | `return 42` | eval=42; C has `int main` + `return` + `42` |
| B | `let x=1; return x` | eval=1; emit `int32_t` |
| C | `return 1+2` | eval=3; emit `+` |
| D | `return y` undeclared | **sem reject** |
| E | `let a=10; let b=a+5; return b` | eval=15 |

## Phase 4 (domknięte)

Pętla podzbioru — **nie** pełny rewrite `kcc` w K0:

```text
stage0 rustc → host kcc → selfhost_dump.k0 → stdout C → gcc → exit 42/1/3/15
```

| Krok | Kto |
|------|-----|
| Buduje dump | host `kcc` (bootstrap) |
| Emituje C gościa | `emit_engine` w K0 (`putchar` → plik) |
| Link | obce `gcc` |
| Bramka | `.\toolchain\verify_selfhost.ps1` → `KCC_SELFHOST_OK` |

Fixtures A/B/C/E kompilują się i wracają 42 / 1 / 3 / 15. D (undeclared) nadal reject.

**Nie twierdzimy:** kcc-k0 kompiluje cały `tok_kind.k0` / `emit_mini.k0` / siebie. Bufor src to 64 bajty; język P4 to `fn` / `let` / `return` / `+` `-`.
