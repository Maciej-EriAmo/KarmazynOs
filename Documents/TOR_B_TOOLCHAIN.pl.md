## Decyzja (2026-08-06) — TB.0

| | |
|--|--|
| **Kompilator** | **musi być własny** (`kcc` — język K0 → C) |
| **Edytor / IDE / OS** | mogą być obce |
| **stage0** | host `rustc`/`cargo` **tylko** żeby zbudować `kcc` raz |
| **Linker / `gcc`** | obce **środowisko** (asemblacja/link IL w C); frontend+codegen = nasz |

> Wzorzec LFS/Gentoo: **własne narzędzia** kompilują **ważne biblioteki**.  
> Nie wymagamy własnego edytora ani własnego OS na start — wymagamy **własnego kompilatora**.

## Własny kompilator: `toolchain/kcc`

| Element | Ścieżka |
|---------|--------|
| Crate | `toolchain/kcc` |
| Język | **K0** (fn, typy i32/i64/f64/bool, if/while, arytmetyka) |
| Backend 0.1 | emit **C99** (IL); link: foreign gcc |
| Krytyczne lib | `thermal*`, `tick_skeleton`, `atom_table`, **`store_mini`** (T×reach) |
| K0 język | + fixed arrays `[T; N]`, `a[i]`, zero-init `let a: [T; N];` |
| Golden TB.3 / 3b | `native/karmazyn_slab/src/golden_k0.rs` (thermal + reach) + `toolchain/golden_k0_thermal.py` |
| Bramka | `.\toolchain\verify_kcc.ps1` → `KCC_VERIFY_OK` |

### Co jest „własne” vs „obce”

| Own | Foreign |
|-----|---------|
| `kcc` (lex/parse/codegen) | VS Code / edytor |
| źródła `.k0` krytycznego prawa | Windows/Linux host |
| artefakt C z bannera `generated by kcc` | `rustc` tylko stage0 (bootstrap kcc) |
| | `gcc` link |

**Nie jest domknięciem self-host:** `kcc` jest jeszcze napisany w Rust i budowany stage0 rustc.  
**Jest startem własnego kompilatora:** ważne progi termiczne **nie** idą przez rustc, tylko przez kcc.
